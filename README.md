# Weekly brief

A one-page weekly brief for a simulated global equity fund, hosted so a small team
can read the same thing without passing files around.

- **[Open the brief](https://tiscode.github.io/weekly-brief-3016dd/)** — where we stand, the
  trades to place this week, and where each position should go. Click any line in the
  book for its investment thesis.
- **[Full detail](https://tiscode.github.io/weekly-brief-3016dd/detail.html)** — the reference
  version: risk statistics, correlation, the frontier, and the regional and sector reads.
  Not needed for the weekly meeting.
- `working-papers/` — the same numbers as plain text, for checking or pasting into slides.

Both pages are self-contained HTML. No build step, no dependencies, no tracking. They
carry a `noindex` directive and the site carries a `robots.txt`, so they should stay out
of search results.

Figures are a simulation for a university course. Nothing here is investment advice.
